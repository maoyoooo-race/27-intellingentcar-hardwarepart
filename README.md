### 快速开始

> 建议不要使用download zip的方式下载代码，因为这样无法进行版本控制和协作开发。请确保你已经安装了Git，并且配置了GitHub账户。

先在本地新建一个文件夹，然后使用以下命令克隆仓库：

```bash
git clone https://github.com/2027-intelligent-car-team/27-intellingentcar-hardwarepart.git
```
每次修改代码之前，请先拉取最新的代码：

```bash
git pull origin main
```
